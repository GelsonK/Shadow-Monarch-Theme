Sobre o Tema (About)

O **Shadow Monarch Theme** foi desenvolvido para programadores que procuram imersão total e foco. Inspirado no universo de *Solo Leveling*, ele combina um fundo escuro profundo com realces fluorescentes para destacar o código de forma precisa, reduzindo o cansaço visual durante longas sessões de programação.

Paleta de Cores & Elementos Gráficos

| Elemento do Editor | Amostra | Cor (Hex) | Função Visual |
| :--- | :---: | :--- | :--- |
| **Deep Background** | ⬛ | `#0D0E12` | Fundo principal (Sombras profundas) |
| **Monarch Aura** | 🟪 | `#9A4BFF` | Funções, classes e palavras-chave principais |
| **Spectral Glow** | 🟦 | `#00E5FF` | Strings, atributos e textos destacados |
| **System Contrast** | ⬜ | `#E0E0E6` | Variáveis e texto padrão de alta leitura |

Instalação Rápida (Installation)

### Método 1: Pelo VS Code (Interface)
1. Abra o **VS Code**.
2. Vá até a aba de Extensões (`Ctrl+Shift+X` ou `Cmd+Shift+X`).
3. Pesquise por `Shadow Monarch Theme` e clique em **Install**.
4. Pressione `Ctrl+K` + `Ctrl+T` e selecione o tema na lista.

### Método 2: Pelo Terminal do Quick Open
Pressione `Ctrl+P` (ou `Cmd+P`), cole o comando abaixo e aperte `Enter`:
```bash
ext install GelsonKito.shadow-monarch-theme
```

### Configurações Recomendadas (`settings.json`)
Para garantir o melhor visual das fontes e do contraste, adicione estas linhas ao seu arquivo de configurações:
```json
{
  "workbench.colorTheme": "Shadow Monarch",
  "editor.fontSize": 14,
  "editor.fontLigatures": true,
  "workbench.iconTheme": "vs-seti"
}
```
